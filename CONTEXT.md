# Nanatau Asset Context

Shared language for the repository's character assets, generated materials, and published visual resources.

## Asset lifecycle

**Reference**:
An existing or external material used to guide creation or comparison. It is an input, not an adopted repository asset.

**Working**:
An in-progress generated or processed material that may be replaced, discarded, or refined.

**Verified**:
A working material that has passed the checks required for its intended use and is eligible for adoption.

**Canonical**:
An adopted material that represents the repository's current source of truth for that asset.

The lifecycle is ordered: **Reference → Working → Verified → Canonical**.
