# 画像・2D素材

採用した画像、参照資料、配信用素材を用途ごとに保存しています。3Dモデル・動画・検証記録は[モデル一覧](../models/README.md)を参照してください。

| 用途 | 保存先 |
| --- | --- |
| 紹介サイトのビジュアルと3D表情 | [Showcase](concept/showcase/README.md) |
| 3Dアバターの採用デザイン・確認画像 | [avatar-v1](concept/avatar-v1/README.md) |
| 従来のキービジュアル・三面図、別案 | [コンセプト一覧](concept/README.md) |
| 表情アイコン7枚 | [icon/](icon/) |
| 透過PNGと動画を使う配信用素材 | [PNGアバター素材](png-tuber/README.md) |
| Codex用ペット2セット | [ペット一覧](pets/README.md) |
| 制作の参照画像・レイアウトテンプレート | [参照資料](reference/README.md) |
| README用ロゴ・見出し・カード | [装飾素材](readme/README.md) |

作業中の生成物はGit管理外の `output/` に置き、採用した画像をこのディレクトリへコピーします。参照資料と採用素材の区別は[素材の管理方針](../docs/adr/0001-asset-lifecycle.md)を参照してください。
