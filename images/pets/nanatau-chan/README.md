# ななたうちゃん

既存のちび体型のCodexペットに、時計回り16方向の視線を追加したv2版です。足元を固定し、目・まぶた・首の動きで周囲を見ます。

- `pet.json`: v2マニフェスト
- `spritesheet.webp`: 1536×2288、192×208セル、8列×11行
- 通常9種類の動作と16方向の視線を収録

`pet.json` と `spritesheet.webp` を同じフォルダーに置き、Codexのカスタムペット領域 `~/.codex/pets/nanatau-chan/` へ配置します。

元の通常動作8行は維持し、髪と靴の切断があった左走り1行を修復しました。元の顔・ちび等身・衣装・杖を視線ポーズの基準にしています。[制作の参照画像](../../reference/pets/nanatau-chan/reference-sheet.png)も保存しています。

画像生成には組み込みの `image_gen`、切り出し・位置合わせ・透過の縁処理・v2検証には `hatch-pet` の処理を使用しました。画像とJSONのみで、実行コードや秘密情報を含みません。
