# ななたう アトリエ

デザインと開発をそっと応援する、ななたうのCodex用ペット。添付のキャラクター三面図をもとに、淡い黄色・紺・クリームのフラットな表現へ整理しました。

- `pet.json`: v2マニフェスト
- `spritesheet.webp`: 1536×2288、192×208セル、8列×11行
- 通常9種類の動作と、時計回り16方向の視線を収録

`pet.json` と `spritesheet.webp` を同じフォルダーに置き、Codexのカスタムペット領域 `~/.codex/pets/nanatau-atelier/` へ配置します。

小さな表示での読みやすさを優先し、細かな鎖・レースを整理しています。ほぼ上下を向くときの左右差と、水平に近い視線の上下差は控えめです。

画像生成は組み込みの `image_gen`、切り出し・位置合わせ・透過の縁処理・v2検証は `hatch-pet` の決定的な処理を使用しました。ペットは画像とJSONのみで、実行コードや秘密情報を含みません。
