# Codex用ペット

| --- | --- |
| [ななたう アトリエ](nanatau-atelier/README.md) | キャラクター三面図をもとに制作したペット |

各フォルダーの `pet.json` と `spritesheet.webp` を一緒に扱います。どちらもv2形式で、通常9種類の動作と16方向の視線を収録しています。配置方法と各セットの制約は、それぞれのREADMEを参照してください。

ななたうちゃんの制作資料は[ペット用の参照画像](../reference/pets/nanatau-chan/reference-sheet.png)にあります。
