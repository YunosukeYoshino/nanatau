# READMEの装飾素材

リポジトリ直下の[README](../../README.md)で使うロゴ・リンクカード・見出し。2026-10-25に制作した。

- `logo.svg`: ななたうの名前と、涙・星・リボンのモチーフ。
- `card-{video,model,gallery}.svg`: 動画・3Dモデル・ビジュアルへの入口。
- `heading-{about,model,materials,start,faq}.svg`: 各セクションの見出し。

配色はPale Butter Yellow（`#FFFDE7`）・Soft Navy（`#2C3E6B`）・Warm White（`#FFF8E1`）。文字はパス化し、外部フォントや画像、スクリプトに依存しないSVGとして保存している。表示用の説明文はSVGの`title`・`desc`とREADMEの`alt`に残す。

作業元はGit管理外の`output/readme-meltype-20261025/assets/`。採用したSVG9点のみをこのディレクトリへコピーした。元のキャラクター画像・3Dモデルは変更していない。

大きなロゴ・画像見出し・リンクカードと折りたたみを使う構成は[MeltypeのREADME](https://github.com/yksr-melt/Meltype)を参考に、ななたうの配色とモチーフで作成した。
