# PNGアバターの配信用素材

静止画の表情差分と、動画に口の画像を重ねるMotionPNGTuberの素材をまとめています。

| 保存先 | 内容 |
| --- | --- |
| [transparent/](transparent/) | 透過ベース画像と、目の開閉・口の開閉を組み合わせた4枚のPNG |
| [opaque/](opaque/) | 背景付きベース画像、表情一覧、クロマキー用画像 |
| [motion/sample/](motion/sample/README.md) | 採用したMotionPNGTuberのループ動画・口画像・ブラウザー用セット |
| [archive/loop.mp4](archive/loop.mp4) | 以前から保存していた、上記セットとは別の動画 |

4枚の透過PNGを作る手順は[PNGTuber制作ガイド](../../.claude/skills/nanatau/PNGTUBER.md)、動画を使う素材の制作・検証は[MotionPNGTuber制作ガイド](../../.claude/skills/motion-pngtuber-nanatau/README.md)を参照してください。作業中の素材はGit管理外の `output/` に保存します。
