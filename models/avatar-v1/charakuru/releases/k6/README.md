# K6の表情付きモデル

2026-10-26に顎先を丸めた、VRM 1.0 / MToonのモデル。まばたきと笑顔を0〜100%で変形できる。最新の[正面顔B](../../studies/true-front-b/README.md)とは顔のバージョンが異なる。

| 用途 | ファイル |
| --- | --- |
| VRMを使う | [avatar.vrm](avatar.vrm) |
| モデルを編集する | [avatar.blend](avatar.blend) |
| 動きを見る | [motion.mp4](motion.mp4)：12秒・1540×900・24fps・無音 |
| 表情と全身を見る | [画像一覧](../../../../../images/concept/avatar-v1/charakuru/README.md#現在の表情と全身) |
| 検証結果を読む | [モデル](verification/model.json)・[動作](verification/motion.json)・[動画](verification/video.json)・[再生](verification/playback.json)・[制作](verification/production.json) |

動画は左右の首振り、うなずき、まばたき、笑顔を全身と顔アップで確認するもの。揺れ物の物理を新たに計算した動画ではない。口パク・LookAt・配信アプリ・本人トラッキング・実配信時の負荷は未検証。

編集方法と利用条件は[制作記録](../../PRODUCTION.md)、ファイルのサイズとSHA-256は[manifest](../../manifest.json)を参照する。
